# Ecommerce SQL Data Analysis

## Project Overview

This project performs SQL-based analysis on an ecommerce dataset containing 1,200 order records.

The dataset was prepared in Microsoft Excel, exported as a CSV file, and imported into SQLite using DB Browser for SQLite.

SQL queries were then used to retrieve, filter, sort, group, and aggregate the data to generate useful business insights.

## Project Objectives

- Use SELECT queries to retrieve data
- Filter records using WHERE
- Sort results using ORDER BY
- Group records using GROUP BY
- Perform aggregations using COUNT(), SUM(), and AVG()
- Extract useful insights from ecommerce order data

## SQL Analysis

### 1. Total Orders

```sql
SELECT COUNT(*) AS TotalOrders
FROM orders;
```

**Result:**

- Total orders: 1,200

This query was used to verify that all 1,200 records were successfully imported into the SQLite database.

### 2. Delivered Orders

```sql
SELECT *
FROM orders
WHERE OrderStatus = 'Delivered'
LIMIT 10;
```

This query uses the WHERE clause to filter the dataset and display only orders with a Delivered status.

### 3. Highest-Value Orders

```sql
SELECT
    OrderID,
    Product,
    Quantity,
    UnitPrice,
    TotalPrice
FROM orders
ORDER BY TotalPrice DESC
LIMIT 10;
```

This query sorts the orders by TotalPrice from highest to lowest and displays the 10 highest-value orders.

### 4. Revenue by Product

```sql
SELECT
    Product,
    ROUND(SUM(TotalPrice), 2) AS TotalRevenue
FROM orders
GROUP BY Product
ORDER BY TotalRevenue DESC;
```

**Key Findings:**

- Chair generated the highest overall revenue: 195,620.11
- Printer generated the second-highest revenue: 195,612.61
- Phone generated the lowest overall revenue: 151,722.39

This query groups all orders by product and calculates the total revenue generated by each product.

### 5. Orders by Status

```sql
SELECT
    OrderStatus,
    COUNT(*) AS NumberOfOrders
FROM orders
GROUP BY OrderStatus
ORDER BY NumberOfOrders DESC;
```

**Results:**

- Cancelled: 250
- Returned: 247
- Pending: 237
- Shipped: 235
- Delivered: 231

Cancelled orders were the most common order status, while Delivered orders were the least common.

### 6. Average Unit Price by Product

```sql
SELECT
    Product,
    ROUND(AVG(UnitPrice), 2) AS AverageUnitPrice
FROM orders
GROUP BY Product
ORDER BY AverageUnitPrice DESC;
```

This query calculates the average unit price for each product and sorts the results from highest to lowest.

### 7. Delivered Revenue by Product

```sql
SELECT
    Product,
    COUNT(*) AS DeliveredOrders,
    ROUND(SUM(TotalPrice), 2) AS DeliveredRevenue
FROM orders
WHERE OrderStatus = 'Delivered'
GROUP BY Product
ORDER BY DeliveredRevenue DESC;
```

**Key Findings:**

- Laptop generated the highest delivered-order revenue: 40,714.43
- Laptop had 40 delivered orders
- Phone generated 40,348.41 from 38 delivered orders
- Desk generated the lowest delivered-order revenue: 24,236.78

This query combines filtering, grouping, counting, aggregation, and sorting in a single analysis.

## Key Insights

- The dataset contains 1,200 ecommerce orders.
- Chair generated the highest total revenue overall.
- Printer generated almost the same total revenue as Chair.
- Phone generated the lowest total revenue overall.
- Cancelled orders were the most common order status.
- There were 231 delivered orders.
- Laptop generated the highest revenue among delivered orders.
- SQL made it possible to quickly filter, sort, group, and summarize the ecommerce dataset.
